# EduSkills Academy — Modern & Vibrant Homepage Patch

This patch replaces only the homepage component and adds a homepage-scoped stylesheet.

## Included
- `src/pages/Home.jsx`
- `src/pages/Home.css`

## Apply
1. Back up your project first.
2. In your local project, replace `src/pages/Home.jsx` with the file in this patch.
3. Copy `src/pages/Home.css` into your project's `src/pages/` folder.
4. Keep `src/index.css`, `src/App.jsx`, `src/data/academy.js`, the Navbar, Footer, and all other pages unchanged.
5. Run `npm run build` and preview locally before committing or deploying.

This patch uses the existing React Router routes, `lucide-react` icons, and `src/data/academy.js`.
It does not change GitHub or your live website by itself.

Note: The hero artwork is CSS illustration rather than an external stock photo. Verify class ranges and programme labels against the academy's current offering before publishing.
